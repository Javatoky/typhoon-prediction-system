# 数据卡片（Data Card）

本文件是「数据与模型」这条线的**口径裁决记录**，也是数据集的唯一权威说明。
凡与 `backend/app/ml/schema.py`、`backend/training/prepare_data.py` 不一致之处，以本文件为准；
口径变更必须走第 4 节的变更流程。

- 数据集：IBTrACS v04r01（NOAA/NCEI），西北太平洋（WP）子集
- 文件：`data/raw/ibtracs.WP.list.v04r01.csv`（109.3 MB，249,029 行 × 174 列）
- 体检依据：`docs/data-recon-report.md`（阶段 0 侦察结果）
- 冻结日期：2026-10-14
- 裁决人：项目组长（数据与模型负责人）

## 1 口径裁决（已冻结）

每条记录格式：**决策 / 备选 / 理由 / 影响**。

### D-01 风速列：`USA_WIND`

| 项 | 内容 |
| --- | --- |
| 决策 | `max_wind_mps = USA_WIND × 0.514444`（knot → m/s） |
| 备选 | `WMO_WIND`（与国标 10 分钟平均口径一致，但缺失 87.84%）；`CMA_WIND`（覆盖 53.46%，但与其他机构分歧最大） |
| 理由 | 覆盖率最高（54.42%），是科研最通用的列；改用 WMO_WIND 会使样本量进一步崩塌 |
| **必须在报告中披露** | `USA_WIND` 为**1 分钟平均最大持续风速**，而 GB/T 19201-2006 的强度等级阈值基于 **10 分钟平均**。二者口径不同，同一风速下等级可能相差一级。等级结果仅作教学展示。 |
| 影响 | 强度等级分布偏"强"；与国标逐条比对时会有系统性差异 |

### D-02 气压列：`USA_PRES` 为主，`WMO_PRES → CMA_PRES → HKO_PRES` 回退填补

| 项 | 内容 |
| --- | --- |
| 决策 | 优先 `USA_PRES`；缺失时依次用 `WMO_PRES`、`CMA_PRES`、`HKO_PRES` 填补 |
| 备选 | ① 只用 `USA_PRES`；② 单独改用 `WMO_PRES`；③ 单独改用 `CMA_PRES` |
| 理由 | `USA_PRES` 缺失 83.05%，是样本量的主要瓶颈之一 |
| **实测收益（修正）** | 回退填补使估算样本 **6,253 → 6,584（+5.3%）**、可用台风 725 → 754。**不是最初估算的 3.4 倍**——初版估算漏掉了年份与 synoptic 过滤，已修正（见第 6 节） |
| **关键发现** | 单独换任何一列都不如 `USA_PRES`：`WMO_PRES` 6,109、`CMA_PRES` 5,948、`HKO_PRES` 5,161、`TOKYO_PRES` 5,834。回退合并确实优于任何单列 |
| 代价 | **跨机构口径混合**：实际填补 2,035 行来自 WMO、483 行来自 CMA、116 行来自 HKO，占最终可用点位的 15.4% |
| 缓解要求 | ① 填补点标记 `quality_flag=interpolated` 且记录 `pressure_source=fallback:XXX`；② 数据卡片与报告披露填补比例；③ 可用 `--min-year` 之外再跑一次"仅 USA_PRES"对照实验 |

### D-03 取样口径：按 synoptic 时刻重采样

| 项 | 内容 |
| --- | --- |
| 决策 | 只保留 `ISO_TIME` 落在 **00/06/12/18 UTC** 的记录，再按严格 6 小时连续性切窗口 |
| 备选 | ① 直接用原始记录要求 6 小时间隔（实测样本 = 0）；② 对 3 小时记录插值降频（**已否决**） |
| 理由 | IBTrACS 主记录为 3 小时间隔（占 92.77%），严格 6 小时仅占 0.0%。synoptic 重采样是气象资料的标准做法——**取标准观测时刻，不做任何插值** |
| 影响 | 可用记录 31,691 → 15,789（保留 49.82%）；样本从 0 变为 5,873 |
| 明确否决 | **禁止插值降频**：不得为了凑样本量而制造不存在的观测 |

### D-04 年份范围：2000 年 1 月 1 日起

| 项 | 内容 |
| --- | --- |
| 决策 | 只使用 `ISO_TIME >= 2000-01-01` 的记录 |
| 备选 | 全量（1884 年起） |
| 理由 | 分年代样本量显示：1960s/1970s/1990s 合计 **0 个样本**，2000 年前无有效训练数据。纳入只会增加噪声与不可比性 |
| 影响 | 样本全部来自 2000s(2,616) / 2010s(2,196) / 2020s(1,061)；报告中说明"1884–1999 因关键要素缺失未纳入" |

### D-05 跨盆地记录：按 SID 整体保留，不按行过滤

| 项 | 内容 |
| --- | --- |
| 决策 | 只要求台风的**任一部分**落在 WP 即保留该台风**全部**记录（含 `BASIN=EP/NI` 的段落） |
| 备选 | 按行过滤 `BASIN == 'WP'` |
| 理由 | 485 个台风带多个盆地标签（5,368 条非 WP 记录），典型情形是"生成于 WP、东传越过 180°"。按行过滤会把完整轨迹**切成两半**，破坏输入窗口的时间连续性（DQ-04） |
| 影响 | 保留约 1,430 条本会被丢弃的记录；轨迹完整性优先于盆地纯度 |

### D-06 性质过滤：仅保留 `NATURE == 'TS'`

| 项 | 内容 |
| --- | --- |
| 决策 | 只保留热带气旋性质（`TS`）的记录 |
| 备选 | 保留 `ET/MX/NR/DS/SS` 等 |
| 理由 | 非 TS 记录（合计 70,077 条）包含温带变性、扰动等阶段，其移动规律与热带气旋不同，纳入会让模型学到错误的动力特征 |
| 影响 | 过滤损失 9,077 条记录；轨迹可能因此断裂（若断裂则无法构成窗口，属预期行为） |

### D-07 经度口径：统一为 −180 ~ 180

| 项 | 内容 |
| --- | --- |
| 决策 | 入库前把 0~360 口径统一换算为 −180~180（`app/utils/units.py::normalize_lon`） |
| 备选 | 保留 0~360 |
| 理由 | 系统内部与前端地图（Leaflet）均使用 −180~180；实测数据为 0~360（范围 56.0~266.9，其中 3,836 条 > 180） |
| 影响 | 跨 180° 的台风在库中表现为从 +179 跳变到 −179。**地图绘制与误差计算均不受影响**（Haversine 按最短球面路径），但需在数据卡片中记录该现象 |

### D-08 物理量程（修正原配置）

| 字段 | 冻结范围 | 依据 |
| --- | --- | --- |
| `lat` | [−90, 90] | 实测 0.1 ~ 70.1 |
| `lon` | [−180, 180]（存储） | 实测换算后 |
| `max_wind_mps` | **[0, 110]** | 实测最大 **95.17 m/s**；原配置上限 62 m/s 过紧，会误删真实极值 |
| `central_pressure_hpa` | [850, 1020] | 实测 879 ~ 1014 |

### D-09 特征与窗口（沿用需求文档，未变更）

| 项 | 值 |
| --- | --- |
| 特征顺序 | `lat, lon, max_wind, central_pressure`（**不得调整**） |
| 输入长度 | 5 个 6 小时观测点（24 小时） |
| 输出长度 | 12 个 6 小时时效点（最长 72 小时） |
| 划分方式 | 按 `SID` 划分（DQ-06），禁止同一台风跨集合 |

### 2.4 已知限制（必须写入报告）

1. **样本量有限**：总共 6,584 个样本，训练集 4,584 个（330 个台风）。对 Transformer 而言偏小，需配合小模型（d_model=64、2 层）与早停；若指标不稳定，需在报告中如实说明并给出改进方向。
2. **风速口径差异**：`USA_WIND` 为 1 分钟平均，与 GB/T 19201 的 10 分钟平均不同，强度等级仅作教学展示。
3. **气压跨机构混合**：2,634 个点位（15.4%）的气压来自非 USA 机构填补（WMO 2,035 / CMA 483 / HKO 116），存在系统性偏差风险。
4. **时间分辨率下降**：原始 3 小时记录降为 6 小时，台风快速增强阶段的细节被平滑。
5. **经度跨 180° 跳变**：库内表现为 +179 → −179（地图与 Haversine 计算不受影响）。
6. **中国近海样本占比**：区内记录 137,677 条（55.29%），涉及 3,387 个台风，展示与测试具备条件（3.1 要求）。
7. **年份截断代价大**：年份下限从全量收到 2000 年，使台风数从 4,254 降到 822（−80.7%）。这是采样口径（D-03）与要素齐全度共同造成的，不是数据缺失问题。

## 4 变更流程

口径一旦冻结，任何修改都必须：

1. 在本文件新增一条决策记录（含决策/备选/理由/影响四要素），**不得就地改写历史记录**；
2. 说明该变更会使哪些既有实验结论失效；
3. 若已训练模型，需重新训练并更新模型元数据中的 `data_version`。

## 5 实施记录（阶段 2 中发现的缺陷与修正）

实现 `prepare_data.py` 时发现的三个缺陷。它们都属于"代码看起来对、结果悄悄错"的类型，
记录下来供后续维护参考。

### 缺陷 1：列名隐式映射导致"读错机构列"（严重）

| 项 | 内容 |
| --- | --- |
| 现象 | 管线的风速可用行只有 12,945、气压 16,861，比独立估算少约 3,500 行；台风数少 111 个 |
| 根因 | IBTrACS 有多家机构的**同义列**（`USA_WIND`/`WMO_WIND`/`CMA_WIND`/`TOKYO_WIND` 都映射为标准名 `max_wind_mps`）。归一化用"先到先得"，结果风速取了列序在前的 `WMO_WIND`、气压取了 `TOKYO_PRES`——**与冻结口径 D-01/D-02 不符** |
| 修正 | 改为**显式映射**（`build_rename_map`）：只把冻结口径指定的列映射为标准名，回退列用 `pressure_fallback__<机构>` 独立命名，其余机构列不映射 |
| 修正后 | 风速可用 17,315 行、四特征齐全 17,126 行、样本 6,584 —— 与独立估算一致 |
| 教训 | **同义列绝不能用"先到先得"的隐式映射**；口径一旦冻结，列映射必须写死并留日志 |

### 缺陷 2：风速单位判定在归一化之后进行（严重）

| 项 | 内容 |
| --- | --- |
| 现象 | 日志显示"原始单位 mps"，风速未从 knot 换算，整体偏大 1.94 倍 |
| 根因 | 单位判定依赖原始列名（`USA_WIND` 等），但调用时列名已被归一化为 `max_wind_mps`，线索丢失 |
| 修正 | `detect_wind_unit` 改为接收**归一化之前的原始表头**；无法识别时按 knot 处理并告警（宁可换算也不要漏换算） |
| 验证 | 标准化器风速均值 33.62 m/s（约 65 knot），符合台风量级；若未换算会接近 65 m/s |

### 缺陷 3：阶段 0 的样本量估算高估（方法缺陷）

| 项 | 内容 |
| --- | --- |
| 现象 | 侦察报告一度给出"回退填补使样本从 5,873 提升到 20,063（3.4 倍）"，据此做的决策依据是错的 |
| 根因 | 替代方案估算**漏掉了年份下限与 synoptic 过滤**，把 1884 年以来的可用行也算进去了 |
| 修正 | `pressure_source_tradeoff` 改为先应用年份 + synoptic + NATURE + SID 级盆地，再比较 |
| 修正后 | 单列对比：`USA_PRES` 6,253 > `WMO_PRES` 6,109 > `CMA_PRES` 5,948；回退合并 6,584（**+5.3%**） |
| 结论变化 | D-02 决策**仍然成立**（回退合并确实优于任何单列），但收益从"3.4 倍"修正为"5.3%" |
| 教训 | 任何"替代方案对比"必须与主口径使用**完全相同**的过滤条件，否则结论会失真 |

## 6 复现方式

```bash
cd backend
python scripts/fetch_ibtracs.py --basin WP   # 下载（约 109 MB，支持断点续传）
python scripts/data_recon.py                 # 生成体检表 docs/data-recon-report.md
python scripts/verify_dataset.py             # 数据集完整性核验（42+ 项断言）
python training/prepare_data.py --input ../data/raw/ibtracs.WP.list.v04r01.csv
```

产出：

| 文件 | 内容 |
| --- | --- |
| `data/processed/dataset.npz` | `x_train/y_train/x_val/y_val/x_test/y_test` |
| `data/processed/scaler.json` | 四特征均值/标准差（仅由训练集拟合） |
| `data/processed/dataset_meta.json` | 口径留痕、划分清单、统计量（可复现） |
